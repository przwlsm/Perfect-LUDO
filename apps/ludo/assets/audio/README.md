# Original game sounds

These six short PCM WAV effects are synthesized by `scripts/generate-sounds.mjs`
using sine waves and deterministic noise. They contain no recordings, music,
or third-party samples. Regenerate with `node scripts/generate-sounds.mjs`.

The generated audio assets are offered under CC0 1.0 (public-domain dedication):
https://creativecommons.org/publicdomain/zero/1.0/
No attribution is required. The app plays them softly, respects silent mode,
and provides a Game sounds switch. No microphone access is needed.
